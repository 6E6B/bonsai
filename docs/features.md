# Beyond the website

Features beyond the website, with the command that reaches each.

| Feature | Where | Command |
|---|---|---|
| Which of your accounts own an item | Item page, "Your accounts" | — (shows on every item page) |
| Item values, demand, trend and projected/hyped/rare flags (Rolimons, opt-in) | Item page, inventory, trades | Turn item values from Rolimons on or off |
| Resale price history (daily average and volume) as a chart or table, with range, zoom and log scale | Item page → Price history | Set the price history range; Zoom the price history chart; Show the price history on a log or linear scale; Show price history as a chart or a table |
| Wishlist with price drops since you added an item | Marketplace → Wishlist | Add to or remove from wishlist |
| Bundle breakdown | Bundle page → In this bundle | — |
| Inventory RAP and value totals, per account and across all accounts | Inventory → Collectibles / All your accounts | Open a user's inventory |
| Inventory sort by RAP, value or demand; filters for copies, wearing and for sale | Inventory | Sort the inventory; Filter the inventory |
| Trade calculator: RAP and value per side, Robux after fee, net and percent | Trades | — (shows on every trade) |
| Warnings on lopsided trades, projected items, on-hold items, item and Robux limits | Trades and New trade | — |
| Keyboard triage of inbound trades (j/k, a, d, c) | Trades → Inbound | Accept / Decline / Counter trade |
| Trade history filter and CSV export | Trades | Copy the trade list as CSV |
| Marketplace results in the command bar (`i:`) | Command bar | Search the Marketplace |
| Chat with live typing, unread counts and pinned chats (local) | Messages → Chat | Pin or unpin this chat |
| Per-chat drafts that survive restarts and account switches | Messages → Chat | — |
| Experience links in chat, messages and forums show a card with Join | Messages, Communities | — |
| Join the person you're chatting with in their game | Messages → Chat header | — |
| Private message search, bulk select, keyboard triage (j/k, x, e, u, r) | Messages → Inbox | Archive / Mark read or unread / Reply |
| Your other accounts' roles on every community page and list | Communities | — |
| Leave several communities in one confirmed action | Communities → Your communities → Select | Leave the selected communities |
| Member list CSV export | Community → Members | Copy loaded members as CSV |
| Keyboard triage of join requests (a, d, x) and bulk answers | Community → Requests | Accept / Decline selected join requests |
| Local transaction ledger: All and custom date ranges, search, minimum amount, pending only, CSV save and copy | Transactions | Go to Transactions; Fetch older transaction history; Save the shown transactions as CSV |
| Every account's balance and period totals side by side | Transactions → All accounts | Go to Transactions |
| Monthly incoming vs outgoing, spending per experience, top items sold, top buyers | Transactions → Insights | Go to Transactions |
| Toast on a new sale (watcher only notifies) | Settings → Notifications | Turn a notification kind on or off (`sales`) |
| Warnings, bans, terminations and voice chat bans on every saved account, with the ban countdown; warned or banned accounts can still be added | Account rail; status bar (live voice ban countdown per account, click to switch); a dialog that blocks the app until you reactivate, sign out or switch account | Reactivate account (accept a warning or an ended ban) |
| Game playlists (local, per account) | Playlists; experience page and game menus → Add to playlist | Go to Playlists; New game playlist; Add this experience to a playlist |
| Many accounts signed in at once, with labels, colors and rail order | Account rail | Switch account; Switch to last used account; Set account color tag |
| Join, buy or add friend as another account | Experience, item and profile pages | Join as another account; Buy this item as another account; Add friend as another account |
| Optional encrypted account vault with a PIN | Settings | Protect all accounts with a PIN; Lock Bonsai |
| Command bar for every action, rebindable shortcuts | Everywhere | Search or run a command; Change a command's shortcut |
| Tabs: pin, duplicate, reopen closed, saved across restarts | Tab bar | New tab; Reopen closed tab; Pin or unpin tab |
| Server picker: best, smallest, random, by job id; player faces; recently played servers | Experience → Servers | Join best server for me; Join smallest server; Join server by job id; Copy server invite link |
| Custom Roblox launch command | Settings | Set how Roblox is launched |
| Private nicknames and notes on people | Profile | Set a nickname for someone; Write a private note about someone |
| Filter friends by status, including followers you don't follow back | Friends | Filter friends by status |
| Desktop alerts for friend joins, trades, chats, requests and experience updates; quiet hours, mute while playing, sound | Settings → Notifications | Turn a notification kind on or off; Turn update notifications on or off |
| Tray icon, close to tray, start on login | Settings | — |
| Themes: editor with undo, contrast fix, fonts, import/export as code or file | Themes | New theme; Fix low contrast in the theme; Import theme |
| Background picture with blur, dim, tint, grain and other effects | Settings → Appearance | Set background picture; Background level |
| Theme hub with GitHub sign-in (plugins switched off for now) | Hub | Go to Theme and Plugin Hub; Publish theme release |
| Luau plugins with permission tiers, per-account automation, caps and activity log | Plugins | Install plugin; Show plugin activity |
| Fandom wiki articles for experiences and items | Wiki; experience and item pages | Search the wiki; Read the wiki article about this; Turn wiki articles from Fandom on or off |
| Item dependency browser | Item page → Dependencies | View this item's dependencies; Search this item's dependencies |
| Clothing template download, plain or masked | Item page | Download clothing template; Download clothing template, masked |
| 3D viewer that plays animations and emotes, and tries on items and bundles | Avatar, item and bundle pages | Play an animation in the 3D view; Try on this item in 3D |
